# Kubernetes Observability Platform

A Kubernetes observability platform built on AWS EKS.

## Technology Stack

- AWS EKS
- Terraform
- Docker
- Kubernetes
- Helm
- Prometheus
- Grafana
- Alertmanager
- GitHub Actions

## Project Goals

- Provision Kubernetes infrastructure using Terraform.
- Deploy a containerised application.
- Collect Kubernetes and application metrics.
- Visualise metrics using Grafana.
- Configure monitoring alerts.
- Automate infrastructure and application deployment.
